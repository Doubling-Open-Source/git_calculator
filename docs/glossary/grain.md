# grain

How commits that already passed the [window](window.md) are aggregated into rows: **`weekly`** (ISO week `YYYY-Www` in UTC) or **`monthly`** (calendar month `YYYY-MM` in UTC). Grain does not change which commits count. Contract: [window and grain](../features/window-and-grain.md). Usage: [choose window and grain](../client/choose-window-and-grain.md).
